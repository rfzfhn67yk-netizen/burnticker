# Burnticker

Memecoins whose supply burns when an adjudicated real-world event settles — with an on-chain receipt anyone can recompute.

- Site: https://burnticker.com · Whitepaper: https://burnticker.com/whitepaper.html · First coin: https://deficit.burnticker.com
- Status (2026-10-10): the program, keeper, platform and SDK are being carved out of a private monorepo through an allowlist with a leak scan; the full source lands here after the devnet rehearsal. Three independent code reviews are published at https://burnticker.com/burnticker/trust.
- Operated by one independent operator (United States). A memecoin — the rule says what supply does, not what price does.
