# Launch wizard product-logic audit, 2026-10-19

Scope: options, lines and costs the launch wizard, the review card and the coin page show a creator, checked against what the chosen rule can actually do. Not a security audit and not a whole-repo review. Commit audited: 7f2f487e (the main checkout's branch head this morning).

Method: the conditions in `src/app/burnticker/launch/page.tsx` were followed by hand for each rule shape, and the read-only review (`buildLaunchReview` in `src/lib/burnticker/launchReview.ts`) was run in-process for every shape at 2%, 50% and 100%, with and without a burn target, the incinerator end and a named-coin end, on three host settings (mainnet with the r5 layout off, mainnet with r5 on, r5 on with dispersal off). The live catalogue was read once (GET only): mainnet, launches open, hosted signing complete, sports on, pair curve on, `burn-real` on, end-sink picker off.

Every finding is reproduced in `test/burntickerLaunchWizardAudit.test.ts`. Where the code is wrong, the test asserts today's behaviour and says so, with the wanted behaviour as a `test.todo` beside it.

## Round 5 leaks when the host merely runs r5

1. Step 3 of every single coin (not vault, not pair): `BurnRealChoice` with WIF and BONK (`page.tsx:749`, `:2013`). The owner's earthquake case.
2. Coin vs Coin tile: a per-side "burn the real <coin>" choice for any reference coin with a Solana mint and a Pyth feed (`CoinVsCoinTile.tsx:348`, `:597-600`).
3. The review card's notes: `realReviewNotes` (`page.tsx:1879`), and the blockers `realBlockers` (`page.tsx:2113`).
4. The catalogue and the v1 catalogue: `launches.sources` lists `burn-real: available` (live today).
5. The coin page: `ruleRealBurn`, `realHeldLine` and the target receipt lines (`t/[ticker]/page.tsx:172-173`). These read the coin's own rule, so they are right for a coin that has a target and stay silent otherwise; no change needed.
6. The end-sink picker's incinerator choice and the "Other ends, not used here" incinerator row are gated on `burnSol`, which no host emits, so they never show (correct), but see F3 and F4 for the server and draft side.
7. Server: the review and prepare accept `burnTarget` on any host (F2) and the incinerator on any r5 host (F3). The named-coin end is the only round-5-era option the server gates with the same flag as the page.
