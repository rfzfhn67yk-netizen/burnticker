DEV FEE
Burnticker takes 0.25% of curve volume. After graduation, every coin pays 1.25% per swap (Raydium fee tier 14): about 0.98% to the burn pool, 0.13% to the operator and 0.15% to Raydium. LaunchLab moves a graduating coin into a pool on the platform's current fee tier, which is 14; coins made before 19 October 2026 recorded tier 9 when they were created and pay 1.25% all the same. The burn program running today accepts only the tier a coin recorded when it was made, so it would not yet register these coins' tier-14 pools. A program upgrade that accepts the tier LaunchLab actually uses is prepared and not yet deployed; until it is, a coin that graduates collects its fees but does not burn. Coin-vs-coin pair pools use their own split, shown on the pair page. The fee ledger
