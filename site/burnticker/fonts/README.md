# Fonts for the static pages

The latin subsets of Courier Prime (400, 700) and Space Grotesk (variable, 300 to 700), the same files next/font serves the app from
Google Fonts. Both families are licensed under the SIL Open Font License 1.1, and the full license travels with the files:
OFL-CourierPrime.txt and OFL-SpaceGrotesk.txt in this directory, each with its family's copyright line as google/fonts states it (no
Reserved Font Name for either). deploy-sites.sh copies this directory, the two license files included (not this README), with the rest
of site/burnticker. The app's own copies of the fonts are generated by next/font at build time; the same two license files ship with
the app at config/public-repo/overlay/public/burnticker/fonts/ (served at /burnticker/fonts/). src/lib/burnticker/siteNav.mjs
SHELL_FONTS names the font files.
