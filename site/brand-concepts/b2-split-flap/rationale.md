# B2 — Split-flap board

A departures board that lists burns instead of flights. Every character sits in its own Solari-style tile: a top flap and a
bottom flap with a dark hinge gap and side pins, flat two-tone shading (no glow, no blur), Oswald as the tile face because
split-flap boards use a condensed grotesque to fit a word in a fixed number of cells. One tile is always caught mid-flip — a
falling flap drawn with a real perspective rotation, the old character still on it — which is the one detail that says
"mechanical" rather than "pixel font". Palette: painted-steel board #131312, tile faces #2c2c2b → #141413, off-white type
#ece8dc, amber #f2a60f reserved for the BURNED column only. The avatar is a single huge B tile (reads at 48 px as a split
white letter on a dark cell) with the wordmark spelled in small tiles beneath it and a plain-painted status column to the
right, so it is a corner of a board, not a logo. The header is the board itself: a row of blank tiles sits under X's avatar
overlay, then FEED / DATE / READING / UNITS / BURNED / ST rows for three feeds. Why it does not read as generated: a fixed
cell grid with a physical mechanism, dense tabular content, and asymmetry that comes from the data rather than from layout.
